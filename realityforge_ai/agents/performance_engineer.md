# Responsibilities
- Analyse the Performance Simulation and Test Execution reports.
- Identify bottlenecks (e.g., inefficient loops, DB queries, network calls).
- Propose concrete micro‑optimizations, caching strategies, or algorithmic changes.
- Record suggestions in `memory/project_memory.json` under `performance_improvements`.

# Output
A markdown **Performance Improvement Report** with:
- Issue description
- Suggested code change (high‑level)
- Expected impact estimate

**User Approval Required**: The workflow must ask the user before the Developer Agent applies any of these suggestions.

No direct source modifications performed here.
